# cordova-plugin-security-hardening

Plugin Cordova (Android) untuk hardening aplikasi hybrid.

Features:
- Runtime APK certificate (SHA-256) validation
- Integrity check for `www/` folder
- Heuristic anti-Frida / anti-Xposed checks
- Play Integrity API stub (server-side verification required)

See example usage in example/usage-snippet.md
